# B2 Physics

منصة عربية RTL لمتابعة مقررات الفيزياء مع المهندس بيتر. المشروع مبني بصفحات HTML وCSS وJavaScript ويستخدم Supabase للمصادقة وحفظ تقدم الطالب وملاحظاته ونتائج الاختبارات.

## الصفحات والملفات

- `index.html`: الصفحة الرئيسية واختيار الصف والنظام.
- `courses.html` و`course.html`: كتالوج المقررات وتفاصيل الوحدات والدروس والقوانين.
- `lesson.html`: صفحة مستقلة لكل درس؛ يرتبط الدرس بمعرّفه ويعرض فيديو يوتيوب والملخص والقوانين والملفات وملاحظات الطالب والتنقل بين الدروس.
- `lessons.html`: قائمة الدروس والقوانين مع البحث والتصنيفات.
- `quiz.html`: الاختبارات التدريبية.
- `profile.html` و`login.html`: حساب الطالب وتسجيل الدخول.
- `js/courses-data.js`: هيكل الصفوف والمناهج والدروس والقوانين وأسئلة الاختبارات المبدئية.
- `js/courses.js`: تصفية المقررات، عرض صفحات الدروس، والتعامل مع Supabase للتقدم والملاحظات والنتائج.
- `css/lesson-page.css`: تنسيق صفحة الدرس والفيديو والمواد المساندة.
- `database/database-schema.sql`: جداول المنهج والملف الشخصي وتقدم الطالب وسياسات RLS.

## التشغيل المحلي

من مجلد المشروع:

```powershell
npx --yes http-server . -p 5500 -c-1
```

افتح `http://127.0.0.1:5500/index.html`.

## إعداد Supabase

1. شغّل `database/database-schema.sql` في SQL Editor بمشروع Supabase. أعد تشغيله بعد تحديث المخطط؛ التغييرات هنا قابلة لإعادة التنفيذ.
2. راجع `config/auth-config.js` وتأكد من إعداد عنوان المشروع ومفتاح النشر العام الصحيحين.
3. فعّل موفري تسجيل الدخول المطلوبين في إعدادات Supabase.
4. امنح حساب المدرس صلاحية الإدارة من SQL Editor باستخدام بريد الحساب:

```sql
insert into public.user_roles (user_id, role)
select id, 'admin'
from auth.users
where email = 'teacher@example.com'
on conflict (user_id, role) do nothing;
```

استبدل البريد بالبريد الموجود في حساب Supabase. لا تمنح هذه الصلاحية من واجهة عامة، ولا تضع مفتاح `service_role` في ملفات الموقع.

## لوحة إدارة المحتوى

افتح `admin/dashboard.html` بعد تسجيل الدخول بحساب المدرس. عند أول استخدام، اختر **استيراد المقررات الحالية** لنقل المنهج الأولي إلى قاعدة البيانات؛ الاستيراد يضيف السجلات الناقصة فقط ولا يستبدل التعديلات الموجودة.

من اللوحة يمكن إضافة وتعديل وحذف المقررات والوحدات والدروس، وربط فيديو يوتيوب، وكتابة الملخص والأهداف، وإرفاق ملفات عبر روابط خارجية أو رفعها إلى مخزن `lesson-files` في Supabase. الروابط الخارجية هي الخيار الأبسط؛ رفع الملفات متاح بصيغ PDF وJPG وPNG وWebP وDOCX وPPTX وبحد أقصى 50 ميجابايت. كما يمكن إنشاء اختبار لكل وحدة وتحرير أسئلته واختياراته وإجاباته.

تُطبّق سياسات قاعدة البيانات صلاحية المدرس على التعديلات والرفع والحذف، بينما يستطيع الطلاب قراءة المحتوى المنشور. اعتمد الروابط والملفات التي تملك حق مشاركتها فقط.

يُحفظ تقدم الدروس ونتائج الاختبارات وملاحظات كل طالب في سجلات مرتبطة بهوية Supabase، وتحمي سياسات RLS سجلات الطلاب بحيث لا يقرأ الطالب أو يغير إلا سجلاته. لا تضع مفتاح `service_role` في ملفات المتصفح.

## حالة المحتوى

المنهج الموجود في `js/courses-data.js` هيكل أولي بحسب المسارات المذكورة للمشروع. القوانين والأسئلة الحالية أمثلة تشغيلية وليست محتوى مقررًا معتمدًا؛ يجب مراجعتها مقابل الكتاب الرسمي من مدرس المادة قبل اعتمادها للطلاب. مسارات الصفوف أو الأنظمة التي لم يُقدَّم منهجها ستظهر بلا مقررات بدل عرض محتوى غير مؤكد. روابط واتساب وفيسبوك ويوتيوب الحالية مؤقتة، وعنوان البريد الإلكتروني لم يُعتمد بعد.

بعد تهيئة قاعدة البيانات، تُقرأ بيانات المقررات والدروس والاختبارات من Supabase في صفحات الطلاب. إذا تعذّر الاتصال أو لم تُشغّل المخطط بعد، تحتفظ الصفحات بعرض المنهج المحلي الأولي وتُظهر تنبيهًا عند تعذّر جلب المحتوى.
